# 长安幻想·宴会消消乐助手（Android）

这是一个安卓纵屏辅助 App：在手机本地读取游戏画面，识别宴会消消乐棋盘，计算能形成三连的相邻交换，并通过悬浮窗给出提示。用户主动开启“自动滑动”后，App 会使用安卓无障碍手势执行该交换。

1.1.0 已根据用户提供的宴会消消乐真实画面进行专项预设：棋盘为 8 行×7 列，基础图标为 5 类；粉红切片、数字与闪光按消除动画处理，画面稳定前不会执行下一步。

## 当前版本能力

- 支持 4～10 行、4～10 列棋盘，图标种类可设为 4～9。
- 全屏棋盘标定：拖动黄框及四角，适配不同手机分辨率和游戏窗口位置。
- 图像识别：对每格中心区域提取颜色/亮度特征，再用本地聚类区分图标。
- 三消求解：遍历相邻交换，优先选择即时消除格数更多的步骤。
- 两种运行方式：默认只提示；用户开启后才自动滑动。
- 画面稳定检测和动作冷却，降低动画期间连续误触的概率。
- 屏幕分析完全在手机本地完成，不上传截图，也不需要网络。
- 自带 GitHub Actions 云端编译流程。

## 首次使用

1. 安装并打开 App，授予“显示在其他应用上层”权限。
2. 如果需要自动滑动，进入无障碍设置，开启“宴会消消乐自动滑动”。
3. 默认参数已经设为 8 行、7 列、5 类图标。建议第一次关闭自动模式。
4. 点击“开始识别棋盘”，同意系统的屏幕录制提示，然后切回游戏。
5. 点击悬浮窗里的“标定”，拖动黄框，使它只包住完整棋盘，点击“保存标定”。
6. 先观察浮窗建议是否与棋盘一致。确认稳定后，再点击“自动：关”切换为“自动：开”。

## 识别不准时怎么调

- 建议先确认行数、列数和图标种类；这三个参数必须与游戏画面一致。
- 黄框边缘应贴近最外层方块，不要包含倒计时、按钮、人物或大面积背景。
- 浮窗不要遮住棋盘，可按住浮窗左侧状态文字拖走。
- 特殊方块、爆炸动画、半透明遮挡会降低通用颜色聚类的准确率；等待画面稳定后再测试。
- 如果游戏图标主要靠形状而不是颜色区分，需要提供实际截图，为对应图标制作专用模板识别版。

## GitHub 云端编译 APK

1. 新建一个 GitHub 仓库。
2. 将本工程根目录下全部文件（包括 `.github`）上传到仓库根目录。
3. 打开仓库的 **Actions**，选择 **Build Banquet Match3 APK**。
4. 点击 **Run workflow**，等待绿色对勾。
5. 在本次运行底部下载 `ChanganBanquetMatch3-APK`，解压得到 `ChanganBanquetMatch3-debug.apk`。

构建参数：Android Gradle Plugin 8.7.3、Gradle 8.9、Java 17、Android API 35、最低 Android 6.0（API 23）。

## 代码结构

- `MainActivity.java`：权限、棋盘参数和启动界面。
- `ScreenCaptureService.java`：录屏、悬浮窗、稳定检测和运行调度。
- `CalibrationView.java`：游戏内可拖拽棋盘标定层。
- `BoardAnalyzer.java`：每格图像特征和 K-means 图标分类。
- `Match3Solver.java`：相邻交换搜索与评分。
- `AutomationAccessibilityService.java`：仅执行求解器请求的相邻滑动。

## 使用边界

该工程不包含隐藏运行、绕过检测、修改游戏数据、抓包或账号风控规避功能。自动化可能不符合游戏运营规则，请先查看游戏协议，并自行承担测试账号风险。
