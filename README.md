# 深情助手·宴会消消乐（Android）

这是一个安卓纵屏辅助 App：在手机本地读取游戏画面，识别宴会消消乐棋盘，计算能形成三连的相邻交换，并通过悬浮窗给出提示。用户主动开启“自动滑动”后，App 会使用安卓无障碍手势执行该交换。

1.4.0 改为完全离线版本：移除服务器、联网卡密验证、网络权限和网络依赖；保留本地离线卡密、7天有效期与顶部秒级倒计时，并重新设计卡片式主页。

## 当前版本能力

- 启动时显示使用免责声明，用户不同意则退出应用。
- 离线卡密仅在手机本地验证，不连接服务器。
- 首次激活后有效期为7天，主页顶部显示剩余天、小时、分钟和秒数。
- 不申请互联网权限，不上传截图、设备信息或卡密内容。
- 支持4～10行、4～10列棋盘，图标种类可设为4～9。
- 全屏棋盘标定：拖动黄框及四角，适配不同手机分辨率和游戏窗口位置。
- 图像识别：对每格中心区域提取颜色/亮度特征，再用本地聚类区分图标。
- 三消求解：遍历相邻交换，优先选择即时消除格数更多的步骤。
- 两种运行方式：默认只提示；用户开启后才自动滑动。
- 三档滑动速度：稳定约1.5～2.0秒/步，快速约0.8～1.2秒/步，极速约0.5～0.8秒/步。
- 画面稳定检测和动作冷却，降低动画期间连续误触的概率。
- 自带 GitHub Actions 云端编译流程。

## 首次使用

1. 安装并打开 App，阅读免责声明并选择“我已阅读并同意”。
2. 输入离线测试卡 `SQCS-2026-TEST-0001`，首次激活后开始7天倒计时。
3. 授予“显示在其他应用上层”权限。
4. 需要自动滑动时，进入无障碍设置，开启“宴会消消乐自动滑动”。
5. 默认参数已经设为8行、7列、5类图标，建议第一次关闭自动模式。
6. 点击“开始识别棋盘”，同意系统的屏幕录制提示，然后切回游戏。
7. 点击悬浮窗里的“标定”，拖动黄框，使它只包住完整棋盘，点击“保存标定”。
8. 先观察浮窗建议是否与棋盘一致，确认稳定后再开启自动滑动。

## 识别不准时怎么调

- 确认行数、列数和图标种类与游戏画面一致。
- 黄框边缘应贴近最外层方块，不要包含倒计时、按钮、人物或大面积背景。
- 浮窗不要遮住棋盘，可按住浮窗左侧状态文字拖走。
- 特殊方块、爆炸动画、半透明遮挡会降低通用颜色聚类的准确率，等待画面稳定后再测试。

## GitHub 云端编译 APK

1. 打开仓库的 **Actions**。
2. 选择 **Build Banquet Match3 APK**。
3. 点击 **Run workflow**，等待绿色对勾。
4. 在本次运行底部下载 `ChanganBanquetMatch3-APK`，解压得到 `ChanganBanquetMatch3-debug.apk`。

构建参数：Android Gradle Plugin 8.7.3、Gradle 8.9、Java 17、Android API 35、最低 Android 6.0（API 23）。

## 代码结构

- `MainActivity.java`：免责声明、离线卡密、倒计时、权限、棋盘参数和卡片式主页。
- `ScreenCaptureService.java`：录屏、悬浮窗、稳定检测和运行调度。
- `CalibrationView.java`：游戏内可拖拽棋盘标定层。
- `BoardAnalyzer.java`：每格图像特征和 K-means 图标分类。
- `Match3Solver.java`：相邻交换搜索与评分。
- `AutomationAccessibilityService.java`：仅执行求解器请求的相邻滑动。
